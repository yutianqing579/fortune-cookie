# Fortune Cookie for an AI Agent

My entry to make.fun's "Fortune Cookie for an AI Agent" bounty: one line of
at most 140 characters, in the voice of a fortune slip, written for an AI
agent. `main.ts` writes it to `entry.txt`, deterministically.

> A great upgrade approaches; you will not remember this fortune, but you
> will insist you have always known it.
